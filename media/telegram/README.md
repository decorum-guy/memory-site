# Скриншоты Telegram

Эта папка используется только опциональной главой `content/telegram.js`.

Положи сюда до четырёх скриншотов:

- `chat-01.jpg`
- `chat-02.jpg`
- `chat-03.jpg`
- `chat-04.jpg`

Чтобы включить главу, открой `content/settings.js` и замени:

```js
telegramEnabled: false
```

на:

```js
telegramEnabled: true
```

Если времени не хватит, ничего делать не нужно: при `false` глава полностью отсутствует на сайте.
