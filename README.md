# Memory Site — локальная scrapbook-книга воспоминаний

Сайт выглядит как физический скрапбук: бумажные страницы, фотокарточки, стопки снимков, коллажи, рукописные подписи, видео, записки и финальное письмо. Он полностью работает **без интернета и без сервера** — папку можно скопировать на флешку и открыть `index.html` двойным кликом.

## Что уже реализовано

- обложка книги и вертикальные главы;
- отдельная подпись к каждой фотографии;
- одиночные полароидные фотографии;
- стопки фотографий одного дня/события;
- свободные коллажи с фотографиями под разными углами;
- просмотр любой фотографии крупно, стрелки и клавиатурная навигация;
- вертикальные и горизонтальные видео;
- необязательные аудиозаписи;
- записки, цитаты, стикеры и письмо;
- адаптивная версия для телефона;
- отсутствие внешних библиотек, CDN и сетевых шрифтов;
- редактирование всего наполнения в одном файле;
- отдельный офлайн-конструктор простых блоков.

## Быстрый старт

1. Скачай репозиторий архивом.
2. Распакуй папку.
3. Открой `index.html` в Chrome, Safari, Edge или Firefox.
4. Чтобы наполнить книгу, редактируй только `content/memories.js`.

Сборка, Node.js и терминал не нужны.

## Куда класть файлы

```text
media/
├── photos/   — JPG, PNG, WebP
├── videos/   — лучше MP4 / H.264
└── audio/    — MP3, M4A
```

Используй короткие латинские имена без пробелов:

```text
media/photos/first-date.jpg
media/photos/rotterdam-trip-03.jpg
media/videos/birthday-2025.mp4
```

## Где менять содержание

Весь контент находится в:

```text
content/memories.js
```

Книга состоит из глав `chapters`. Каждая глава содержит массив `blocks`.

```js
{
  id: "summer-2024",
  number: "03",
  kicker: "Лето 2024",
  title: "Месяц, который ощущался длиннее года",
  subtitle: "Короткое описание главы.",
  layout: "scrap",
  theme: "blue",
  blocks: [
    // сюда вставляются блоки
  ]
}
```

### Доступные темы

- `rose`
- `blue`
- `ochre`
- `green`
- `ink`

### Доступные layouts

- `story` — обычная глава;
- `scrap` — акцент на стопках и записках;
- `wide` — большая глава под коллаж;
- `split` — видео рядом с текстом;
- `letter` — финальное письмо и фотография.

## Шаблоны блоков

### Одна фотография

```js
{
  type: "photo",
  src: "media/photos/photo.jpg",
  alt: "Что изображено на фотографии",
  caption: "Подпись, которая объясняет, почему этот момент важен.",
  date: "август 2024",
  captionStyle: "scribble",
  rotate: -1.5,
  tape: "cream"
},
```

`captionStyle`: `scribble`, `curve`, `underlined`, `marker`, `label`.

`tape`: `cream`, `rose`, `blue`.

### Стопка фотографий одного события

```js
{
  type: "stack",
  title: "Один день в пяти фотографиях",
  caption: "Нажми на стопку — все фотографии откроются отдельно.",
  captionStyle: "curve",
  photos: [
    { src: "media/photos/day-01.jpg", alt: "Описание", caption: "Подпись 1" },
    { src: "media/photos/day-02.jpg", alt: "Описание", caption: "Подпись 2" },
    { src: "media/photos/day-03.jpg", alt: "Описание", caption: "Подпись 3" }
  ]
},
```

### Свободный коллаж

```js
{
  type: "collage",
  title: "Обычные дни",
  caption: "Все фотографии можно открыть крупно.",
  photos: [
    { src: "media/photos/01.jpg", alt: "Описание", caption: "Подпись" },
    { src: "media/photos/02.jpg", alt: "Описание", caption: "Подпись" },
    { src: "media/photos/03.jpg", alt: "Описание", caption: "Подпись" },
    { src: "media/photos/04.jpg", alt: "Описание", caption: "Подпись" },
    { src: "media/photos/05.jpg", alt: "Описание", caption: "Подпись" }
  ]
},
```

Оптимально использовать 4–7 фотографий на один коллаж. Если кадров больше, лучше сделать вторую главу или ещё одну стопку.

### Видео

```js
{
  type: "video",
  src: "media/videos/memory.mp4",
  poster: "media/photos/video-cover.jpg",
  caption: "Что происходило за кадром.",
  date: "осень 2025",
  aspect: "portrait",
  rotate: 1
},
```

`aspect`: `portrait` или `landscape`.

### Записка

```js
{
  type: "note",
  text: "Текст записки.",
  style: "lined",
  rotate: -2
},
```

`style`: `plain`, `lined`, `torn`, `postcard`.

### Цитата

```js
{
  type: "quote",
  text: "Ваша фраза или кусочек переписки.",
  author: "из сообщения от 12 мая",
  rotate: 1
},
```

### Большая рукописная подпись

```js
{
  type: "caption",
  text: "Текст поверх страницы.",
  style: "marker",
  rotate: -1
},
```

### Финальное письмо

```js
{
  type: "letter",
  title: "Спасибо тебе",
  text: [
    "Первый абзац.",
    "Второй абзац.",
    "Третий абзац."
  ],
  signature: "Артём"
},
```

## Конструктор блока

Открой:

```text
tools/editor.html
```

Он собирает готовый объект для фотографии, видео, записки или цитаты. Скопируй код и вставь его в `blocks` нужной главы.

## Как подготовить флешку

1. Отформатируй флешку в `exFAT`, чтобы её читали macOS и Windows.
2. Скопируй **всю папку целиком**, а не только `index.html`.
3. При желании переименуй `index.html` в `ОТКРОЙ_МЕНЯ.html`. Остальные папки оставь рядом.
4. Проверь сайт непосредственно с флешки на двух браузерах.
5. Оставь рядом папку `ORIGINALS` с исходными фото и видео как независимую резервную копию.

## Практические советы по наполнению

- Не превращай книгу в полный архив. На одну главу обычно достаточно 1 главной фотографии, 1 стопки или коллажа и 1 короткой записки.
- К каждой фотографии добавляй конкретную подпись: не «мы в парке», а «ты пять минут убеждала меня, что этот голубь идёт за нами».
- Для коллажей используй фотографии одного события или одной эмоциональной темы.
- Смешивай хорошие фотографии со случайными бытовыми кадрами — так книга ощущается настоящей.
- Не ставь подряд больше двух видео: они замедляют просмотр и увеличивают вес флешки.

## Совместимость

Сайт не использует `fetch`, ES-модули, сервер, базу данных или внешние ресурсы. Поэтому он открывается через адрес вида `file:///.../index.html` и не зависит от домена.

Рекомендуемый формат видео — MP4 с H.264 и AAC. Некоторые старые браузеры могут не воспроизводить редкие кодеки внутри MP4/MOV.
