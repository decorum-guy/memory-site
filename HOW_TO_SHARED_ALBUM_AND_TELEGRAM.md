# Shared Album и Telegram-глава

Дополнение к `HOW_TO_START.md`. Оба блока необязательные и по умолчанию выключены.

## Shared Album: QR и прямая ссылка

1. В приложении «Фото» создай общий альбом и получи публичную ссылку.
2. Активируй Python-окружение проекта:

```bash
cd ~/Desktop/memory-site
source .memory-venv/bin/activate
```

3. Создай QR-код и автоматически включи карточку:

```bash
python3 tools/generate_shared_album_qr.py "ВСТАВЬ_ССЫЛКУ_SHARED_ALBUM"
```

Команда:

- создаст `media/shared-album-qr.png`;
- запишет ссылку в `content/settings.js`;
- установит `sharedAlbumEnabled: true`;
- оставит QR локальным, чтобы сама карточка выглядела нормально и без интернета.

На финальном сайте после последней страницы появятся:

- красиво оформленный QR;
- кнопка «Открыть Shared Album»;
- сама прямая ссылка;
- кнопка копирования ссылки.

Открытие альбома требует интернет. Сам сайт и QR продолжают работать офлайн.

Чтобы временно скрыть блок, поставь в `content/settings.js`:

```js
sharedAlbumEnabled: false
```

## Telegram: массовый drag-and-drop импорт

Подготовь скриншоты заранее:

- обычные скриншоты можно оставить в JPG или PNG;
- фигурные вырезки сохраняй в PNG с прозрачным фоном;
- не уменьшай их слишком сильно: длинная сторона около 1600–2500 px достаточна;
- прозрачность PNG сохраняется без преобразования.

Запусти локальную студию:

```bash
cd ~/Desktop/memory-site
source .memory-venv/bin/activate
python3 tools/telegram_server.py
```

Откроется `Telegram Studio` в браузере. Сервер слушает только `127.0.0.1`; файлы никуда не отправляются.

В Studio можно:

- перетащить сразу много PNG/JPG/WEBP из Finder;
- менять порядок карточек;
- подписывать каждый фрагмент;
- переключать оформление «Карточка / Вырезка»;
- удалить ненужный элемент из главы;
- задать заголовок, подзаголовок, вступление и финальную цитату;
- сохранить готовую главу одной кнопкой.

После загрузки файлы автоматически копируются в:

```text
media/telegram/
```

После кнопки «Сохранить главу» создаются:

```text
content/telegram-data.json
content/telegram.js
```

Большой набор автоматически разбивается на scrapbook-развороты по 7 элементов. Поэтому 20–40 фрагментов не требуется вручную раскладывать в коде.

PNG с настоящей прозрачностью автоматически получают режим «Вырезка». Для любого элемента режим можно переключить вручную.

После сохранения включи главу в `content/settings.js`:

```js
telegramEnabled: true
```

Если времени не хватило, оставь `false`: Telegram-глава полностью исчезнет из книги и навигации.

## Что проверить перед вручением

- QR сканируется камерой iPhone;
- прямая ссылка открывает именно нужный Shared Album;
- Telegram PNG не получили белый прямоугольный фон;
- длинные подписи не перекрывают изображения;
- на мобильной версии все вырезки остаются читаемыми;
- после выключения интернета основной сайт продолжает работать.
