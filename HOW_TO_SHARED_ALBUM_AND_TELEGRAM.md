# Shared Album и Telegram-глава

Дополнение к `HOW_TO_START.md`. Оба блока необязательные и по умолчанию выключены.

## Shared Album: QR и прямая ссылка

1. В приложении «Фото» создай общий альбом и получи публичную ссылку.
2. Активируй Python-окружение проекта:

```bash
cd ~/Desktop/memory-site
source .memory-venv/bin/activate
```

3. Создай QR-код и автоматически включи карточку:

```bash
python3 tools/generate_shared_album_qr.py "ВСТАВЬ_ССЫЛКУ_SHARED_ALBUM"
```

Команда создаст локальный QR в `media/shared-album-qr.png`, запишет ссылку в `content/settings.js` и включит карточку Shared Album. Открытие ссылки требует интернет, но сама книга и QR отображаются офлайн.

Чтобы временно скрыть блок, поставь в `content/settings.js`:

```js
sharedAlbumEnabled: false
```

## Telegram: записки и выбранные сообщения

Telegram-глава не задумана как полный архив переписки. В ней можно собрать несколько личных записок и важных фраз из чата.

Запусти локальный конструктор:

```bash
cd ~/Desktop/memory-site
source .memory-venv/bin/activate
python3 tools/telegram_server.py
```

Откроется `Telegram Studio`. Сервер слушает только `127.0.0.1`; данные никуда не отправляются.

### Типы блоков

**Записка** — твоё напутствие или небольшой текст от себя. На сайте она выглядит как вырезанный лист бумаги. Кнопка «Сменить край» переключает одну из пяти слегка отличающихся форм рваного края.

**Цитата сообщения** — выбранная фраза из переписки. Для неё указываются:

- текст сообщения;
- автор: Соня или Артём;
- необязательный скриншот именно этого сообщения.

Цитаты Сони оформляются акцентным бордовым цветом, цитаты Артёма — синим. Скриншот, если он приложен, располагается рядом с цитатой и открывается крупно по нажатию.

### Работа в конструкторе

1. Добавь блок кнопкой `＋ Записка` или `＋ Цитата сообщения`.
2. Заполни текст.
3. Для цитаты выбери автора.
4. При необходимости нажми `Добавить скрин` и выбери PNG, JPG или WEBP.
5. Переставляй блоки перетаскиванием.
6. Нажми `Сохранить главу`.
7. Кнопка `Открыть предпросмотр` покажет книгу с временно включённой Telegram-главой.

После сохранения появляются или обновляются:

```text
media/telegram/
content/telegram-data.json
content/telegram.js
```

Для постоянного включения поставь в `content/settings.js`:

```js
telegramEnabled: true
```

Чтобы сравнить книгу без Telegram, оставь:

```js
telegramEnabled: false
```

Даже при `false` подготовленная глава не удаляется — она просто не показывается в книге и навигации.

## Что проверить перед вручением

- QR сканируется камерой iPhone;
- прямая ссылка открывает нужный Shared Album;
- записки идут в правильном порядке;
- авторы цитат окрашены правильно;
- необязательные скриншоты открываются крупно и закрываются крестиком или клавишей Escape;
- PNG с прозрачностью не получили белый прямоугольный фон;
- после выключения интернета основной сайт продолжает работать.
