# Проверка правок — раунд 4

Ветка для проверки: `review-round-2-polish`. В `main` эти изменения пока не слиты.

## Telegram Studio

Запусти из корня тестовой копии:

```bash
python3 ".memory-test/site/tools/telegram_server.py"
```

Проверь:

- [ ] В поле **«Фраза над заголовком»** можно изменить текст «Слова, которые остались»; после сохранения он меняется в Telegram-главе.
- [ ] У записки кнопка **«Сменить край»** сразу меняет форму прямо в конструкторе, без повторного открытия предпросмотра.
- [ ] Короткая записка в книге имеет ширину по содержимому, а не растягивается на весь доступный блок.
- [ ] Для двух коротких записок можно выбрать расположения **«слева»** и **«справа»**; они оказываются на одном уровне с небольшими scrapbook-смещениями.
- [ ] Перетаскивание записок и цитат меняет их порядок.
- [ ] После любого несохранённого изменения кнопка **«Перезагрузить»** показывает подтверждение. Отмена подтверждения сохраняет текущий текст в конструкторе.

## Memory Studio

Открой `tools/studio.html` и проверь:

- [ ] В верхнем блоке можно изменить маленькую надпись, архивную метку, главный заголовок, рукописную подпись, пояснение, текст кнопки открытия и финальную подпись книги.
- [ ] В каждой главе можно изменить год/метку главы, фразу над заголовком, крупный заголовок и текст под ним.
- [ ] После экспорта все эти значения присутствуют в скачанном `memories.js` и применяются после замены файла книги.

## Основная книга

Открой книгу и проверь:

- [ ] У первой главы слева корректно включается active-состояние, включая переход обратно с других глав.
- [ ] Вместо `01`, `02`, `03` для временных глав показываются реальные годы из данных главы.
- [ ] Тот же год показывается маленькой акцентной меткой над крупным заголовком года.
- [ ] Короткая подпись полароида отображается крупнее средней, а длинная — компактнее.
- [ ] Длинная подпись обрезается многоточием и не пересекает нижнюю декоративную полоску.
- [ ] У Live Photo после запуска появляется отдельная кнопка звука; она переключает mute/unmute.
- [ ] Глобальный переключатель цензуры не перезагружает страницу и не прокручивает её к обложке.
- [ ] После возврата цензуры скрытые карточки снова закрыты.
- [ ] Иконка цензуры сохраняет одинаковую геометрию в обоих состояниях и не превращается в случайный символ шрифта.
- [ ] Большая декоративная кавычка у Telegram-цитат находится внутри цветного блока и не выступает вверх за его край.

## Что не должно измениться

- [ ] Курсор остаётся двухсостоянием: basic и active, без hover-версии.
- [ ] Кнопка Live Photo остаётся ниже даты и подписи и ничего не перекрывает.
- [ ] Цвет цитат: Соня — бордовый акцентный, Артём — синий.
- [ ] Скрин цитаты остаётся необязательным и открывается крупно по нажатию.
- [ ] `main` не изменён, PR №6 остаётся draft и не слит.
