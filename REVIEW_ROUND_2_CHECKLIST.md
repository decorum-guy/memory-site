# Проверка ветки `review-round-2-polish`

Эта ветка не слита в `main`. Проверяй её отдельно.

## Как скачать ветку

```bash
cd ~/Desktop/memory-site
git fetch origin
git switch review-round-2-polish
git pull
```

Затем пересоздай тест, потому что структура данных и интерфейсы изменились:

```bash
source .memory-venv/bin/activate
python3 tools/import_workflow.py reset test --yes
python3 tools/import_workflow.py test "$HOME/Desktop/memory-test-input" --open
```

Открыть тестовую Memory Studio:

```bash
python3 tools/studio_workflow.py open test
```

- [ ] Крестик закрывает весь просмотр, не раскрывая файл.
- [ ] После кнопки «Показать» и закрытия галереи конкретная карточка остаётся раскрытой до перезагрузки страницы.
- [ ] Глобальный переключатель цензуры продолжает работать.
- [ ] После применения `memories.test-edited.js` слева видны главы, справа — кнопки читателя.
- [ ] На полароидной карточке показывается человеческая подпись; длинная строка заканчивается многоточием.
- [ ] В полноэкранном просмотре первая строка — дата и время, вторая — человеческая подпись.
- [ ] В Studio превью фото и постеры видео отображаются без битых иконок.
- [ ] Под вводной инструкцией Studio есть расшифровка всех кнопок.
- [ ] У файла в Studio отдельно отображаются дата/время и подпись.
- [ ] Кнопка «Развернуть» увеличивает карточку и поле подписи.
- [ ] Drag-and-drop внутри события и между событиями работает после изменения формы карточки.
- [ ] При 1 файле написано «1 файл», при 2–4 — «файла», при 5+ — «файлов».
- [ ] Событие с одним рядом компактнее, но композиция остаётся воздушной.
- [ ] Событие с 8 файлами показывает два ряда, счётчик читается поверх композиции.
- [ ] При наведении крайняя правая фотография поднимается над соседними.
- [ ] Ни одна фотография не залезает на заголовок следующего события.
- [ ] Видео открываются, запускаются и перематываются.

- [ ] После запуска Live Photo кнопка меняется на «Остановить» и по-прежнему находится ниже даты и подписи.
- [ ] После остановки возвращается статичный кадр.

- [ ] Сердце внутри печатки увеличилось пропорционально.
- [ ] В заголовке «Наши три года» буквы больше не склеиваются, но характер шрифта сохранился.

## Редактор кадра

- [ ] При наведении на превью фото, видео или Live Photo появляется кнопка «Настроить кадр».
- [ ] Редактор открывается как overlay и показывает настоящий полароидный предпросмотр 4:3.
- [ ] Фото, видео и Live Photo можно перетаскивать внутри полароида; исходный файл не меняется.
- [ ] «Отмена» закрывает редактор без сохранения нового положения.
- [ ] «Сохранить» записывает положение, и оно совпадает в Studio и книге.
- [ ] У видео доступна кнопка «Выбрать кадр видео».
- [ ] Ползунок таймлайна позволяет выбрать точное место видео.
- [ ] В выборе кадра «Отмена» возвращает без нового кадра.
- [ ] «Сохранить» возвращает к положению с новым кадром.
- [ ] «Сохранить и выйти» сохраняет кадр и положение и закрывает overlay.
- [ ] После экспорта присутствуют `crop` и `posterTime` только у отредактированных файлов.

## Telegram Studio

Запуск внутри тестовой копии:

```bash
python3 .memory-test/site/tools/telegram_server.py
```

- [ ] Кнопка `＋ Записка` создаёт блок с текстом напутствия.
- [ ] «Сменить край» переключает форму рваной бумажки и не ломает кнопки карточки.
- [ ] Кнопка `＋ Цитата сообщения` создаёт цитату.
- [ ] Для цитаты можно выбрать автора: Соня или Артём.
- [ ] Цитата Сони в книге имеет бордовый акцентный фон.
- [ ] Цитата Артёма имеет синий фон.
- [ ] Скрин сообщения необязателен: цитата нормально выглядит без него.
- [ ] При добавленном скрине он располагается рядом с цитатой и открывается крупно по нажатию.
- [ ] Полноэкранный скрин закрывается крестиком, кликом по фону и клавишей Escape.
- [ ] Блоки можно переставлять перетаскиванием и удалять.
- [ ] После «Сохранить главу» предпросмотр открывается с параметром `telegram=1`.
- [ ] При `telegramEnabled: false` глава полностью исчезает из книги и навигации.

## Кастомный курсор

- [ ] На десктопе в книге отображается оранжевый карандаш.
- [ ] Hotspot обеих версий находится на кончике грифеля: `12 48`.
- [ ] При обычном наведении курсор остаётся basic и не переключается самопроизвольно.
- [ ] Только во время нажатия используется active-версия.
- [ ] В Memory Studio остаётся системный курсор.
- [ ] На тач-устройствах кастомный курсор не влияет на интерфейс.
- [ ] При невозможности использовать SVG браузер загружает PNG-fallback.

## Отдельный коммит layout

Коммит с компактностью событий, окончаниями слова «файл» и геометрией рядов:

```text
fix(layout): compact event heights and safe row geometry
```

Его можно откатить независимо от остальных правок.
