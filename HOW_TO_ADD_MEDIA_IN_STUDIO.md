# Добавление новых фото и видео после production-импорта

Полный production-импорт повторять не нужно. Memory Studio умеет добавлять новые оригиналы поверх уже отредактированной книги, не пересобирая существующие события.

## Запуск

Из корня проекта:

```bash
cd ~/Projects/memory-site
source .memory-venv/bin/activate
python3 tools/memory_server.py
```

Открой:

```text
http://127.0.0.1:8765/tools/studio.html
```

Старый `tools/telegram_server.py` продолжает обслуживать Telegram Studio и применение готового `memories.js`, но новые медиа-endpoint доступны через `tools/memory_server.py`.

## Пакет фото и видео

1. Нажми **«Добавить фото и видео»**.
2. Выбери много файлов, целую папку или перетащи файлы в область загрузки.
3. Оставь режим **«Автоматически создать события по датам»**.
4. Нажми **«Импортировать»**.

Импортёр локально:

- читает даты, GPS, длительность и Apple ContentIdentifier через ExifTool;
- конвертирует HEIC/HEIF в JPEG;
- создаёт полноразмерные фото и превью;
- перекодирует видео в H.264/AAC MP4 и создаёт постеры;
- распознаёт уверенные Live Photo пары;
- группирует только новые файлы по времени, месту и визуальной близости;
- вставляет новые события в подходящую годовую главу по хронологии;
- сохраняет текущие подписи, порядок, crop, posterTime, цензуру, местоположения и другие ручные правки.

Уже существующие события автоматически не объединяются и не перестраиваются.

## Явная Live Photo пара

Для неоднозначной пары отдельно выбери:

- неподвижное фото — HEIC, HEIF, JPG или другой поддерживаемый формат;
- соответствующий ему MOV, MP4 или M4V.

Нажми **«Добавить пару»**. Фото и видео будут импортированы как один элемент `kind: live`; MOV не появится второй самостоятельной видеокарточкой.

Можно подготовить несколько явных пар в одном пакетном импорте.

## Добавление в существующее событие

В поле **«Куда добавить»** выбери конкретный день. Все новые элементы будут добавлены внутрь него и отсортированы по `takenAt`; название, подпись и остальные настройки события сохранятся.

## Безопасность

Перед записью создаётся:

```text
content/memories.before-media-import-YYYYMMDD-HHMMSS.js
```

Загруженные оригиналы обрабатываются локально. Генерируемые файлы сохраняются в `media/generated/`. Временные каталоги `.memory-imports/` и `.memory-import-source/` исключены из Git.

Повторная загрузка тех же исходников не создаёт дубликаты: идентификаторы строятся из content-addressed пути файла, а существующие `id` и `src` проверяются перед слиянием.
