# Как редактировать тестовый сайт

После успешного тестового импорта можно полностью отрепетировать будущую работу с основной книгой: менять подписи, порядок, события и цензуру, а затем открыть результат.

## 1. Открыть тестовую Memory Studio

Из корня репозитория:

```bash
source .memory-venv/bin/activate
python3 tools/studio_workflow.py open test
```

Откроется файл:

```text
.memory-test/site/tools/studio.html
```

Он читает именно тестовую книгу:

```text
.memory-test/site/content/memories.js
```

Основной `content/memories.js` при этом не затрагивается.

## 2. Что можно делать в Studio

- Менять название события.
- Менять общую подпись события.
- Менять подпись каждого фото и видео.
- Перетаскивать фото внутри одного события.
- Перетаскивать фото и видео между событиями.
- Стрелками `↑` и `↓` менять порядок событий.
- Кнопкой `⇧+` объединять событие с предыдущим.
- Создавать новое пустое событие.
- Убирать элемент из книги, не удаляя исходник с диска.
- Помечать конкретное фото или видео цензурой.
- Отменять последние действия.
- Сохранять черновик в браузере.

Изменение текстового поля фиксируется после выхода из поля: нажми `Tab` или кликни в другое место.

## 3. Черновик и настоящий экспорт — не одно и то же

Кнопка **«Сохранить черновик»** сохраняет состояние только в локальном хранилище браузера. Это удобно во время работы, но финальный сайт от этого не изменяется.

Чтобы применить результат:

1. Нажми **«Экспортировать memories.js»**.
2. Браузер скачает `memories.js` в `Downloads`.
3. Выполни:

```bash
python3 tools/studio_workflow.py apply test \
  "$HOME/Downloads/memories.js" \
  --open
```

Скрипт:

- проверит синтаксис файла;
- проверит, что все ссылки на фото, видео, постеры и Live Photo существуют;
- создаст резервную копию предыдущей тестовой структуры;
- заменит только тестовый `.memory-test/site/content/memories.js`;
- откроет тестовую книгу.

Если файл повреждён или в нём появились битые пути, замена не выполняется.

## 4. Рекомендуемая мини-репетиция

На тестовых 50 файлах попробуй:

1. Переименовать одно событие.
2. Написать общую подпись событию.
3. Добавить подписи трём отдельным фотографиям.
4. Перетащить одну фотографию в соседнее событие.
5. Поменять местами две фотографии.
6. Объединить два события.
7. Создать новое событие и перенести туда пару файлов.
8. Пометить одно фото цензурой.
9. Экспортировать и применить `memories.js`.
10. Открыть книгу и проверить все изменения.

Это почти полностью повторяет процесс после настоящего импорта.

## 5. Работа с основной книгой

После полного production-импорта команды будут теми же, только вместо `test` используется `production`:

```bash
python3 tools/studio_workflow.py open production
```

После экспорта:

```bash
python3 tools/studio_workflow.py apply production \
  "$HOME/Downloads/memories.js" \
  --open
```

Для основной книги скрипт отдельно спросит подтверждение и создаст резервную копию.

## 6. Сброс теста

```bash
python3 tools/import_workflow.py reset test --yes
```

Это удалит всю `.memory-test`, включая внесённые тестовые правки. Основная книга останется нетронутой.
